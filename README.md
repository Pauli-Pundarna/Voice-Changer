## 📖 Om projektet

**VoiceBox** är en GUI-applikation som låter dig ändra din röst i realtid. Projektet är byggt som ett gymnasiearbete av tre engagerade gymnasieelever under organisationen **Pauli Pundarna**.

### ✨ Funktioner

- 🎚️ **Realtidsröständring** – hör förändringen direkt, ingen väntan
- 🎵 **Pitch-shifting** – höj eller sänk tonläget på din röst
- 🧪 **Fler ljudeffekter** – experimentera med olika röstfilter
- 🖥️ **Grafiskt gränssnitt (GUI)** – enkelt och användarvänligt

> Fler funktioner är på gång — håll utkik! 👀
